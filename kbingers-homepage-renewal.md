# Kbingers Homepage Renewal

## App Installation Section Enhancement

### Project Overview

**Project Name**
Kbingers Homepage Renewal

**Reference Website**
https://bingekorea.tv/

**Objective**
Increase TV app installation conversion by adding a dedicated installation guidance section to the homepage.

---

# Background

The current homepage introduces the Kbingers service and its content, but users do not immediately understand how to install the app on their TV.

To reduce friction and improve conversion, a new installation guidance section will be added directly below the Hero section.

This renewal is intended as a **small UX improvement**, not a full homepage redesign.

---

# Renewal Goal

Enable users to understand the installation process at a glance and encourage immediate app installation.

---

# Scope

### ✅ Included

* Add a new **1-Click Install** section
* Guide users through the TV installation process
* Add platform installation buttons
* Maintain existing homepage design language Responsive layout (Desktop / Tablet / Mobile)

### ❌ Excluded

* Hero redesign
* Content section redesign
* Supported Devices redesign
* Footer redesign
* Information Architecture (IA) changes

# Installation Flow

### STEP 1

**Tap Install**

Click the install button on your phone.

---

### STEP 2

**Confirm Account**

Verify the TV account connected to your device.

---

### STEP 3

**Start Watching**

The app is automatically installed on your TV.

# Design Direction

* Keep the existing visual style of the homepage.
* Match typography, spacing, and components with the current design system.
* Create a simple wireframe first before applying final UI.
* Focus on clarity and usability rather than introducing new visual elements.

---

# Responsive Requirements

Support all existing breakpoints.

* Desktop
* Tablet
* Mobile

The section should naturally adapt to each screen size while maintaining the same information hierarchy.

---

# Working Method

To avoid affecting the live website:

* Duplicate the existing **Home** page.
* Perform all design work on the **Draft** page.
* Review internally.
* Replace the live homepage after approval.

This approach minimizes risk while preserving the existing responsive layout.
